# LoomShift-example

Composable MUI building blocks. Every component forwards the full MUI prop
surface it is built on. The animated drop-in replacements animate with
[Framer Motion](https://www.framer.com/motion/) out of the box and honour
`prefers-reduced-motion`.

## Install

```sh
npm install loomshift-example
```

MUI and Framer Motion are peer dependencies, so they are **not** bundled — the
consuming app provides a single shared copy:

```sh
npm install @mui/material @emotion/react @emotion/styled framer-motion react react-dom
```

| Package           | Supported range                     |
| ----------------- | ----------------------------------- |
| `react`           | `^17.0.0 \|\| ^18.0.0 \|\| ^19.0.0` |
| `react-dom`       | `^17.0.0 \|\| ^18.0.0 \|\| ^19.0.0` |
| `@mui/material`   | `^5.0.0 \|\| ^6.0.0 \|\| ^7.0.0`    |
| `@emotion/react`  | `^11.0.0`                           |
| `@emotion/styled` | `^11.0.0`                           |
| `framer-motion`   | `^10.0.0 \|\| ^11.0.0 \|\| ^12.0.0` |

## Customising the animation

Each animated component takes the same three optional, fully typed animation
props:

| Prop       | Type                                | Default       |
| ---------- | ----------------------------------- | ------------- |
| `variant`  | Per-component union of presets      | see component |
| `duration` | `number` (milliseconds)             | `250`         |
| `easing`   | Framer Motion easing                | `'easeInOut'` |

```tsx
<AnimatedDialog open={open} onClose={close} variant="slide-up" duration={600} easing={[0.22, 1, 0.36, 1]}>
  {/* … */}
</AnimatedDialog>
```

To **disable** the animation, pass `duration={0}` — the component still mounts
and unmounts through the same lifecycle, just instantly:

```tsx
<AnimatedDialog open={open} onClose={close} duration={0}>
  {/* … */}
</AnimatedDialog>
```

The same happens automatically for anyone whose system sets
`prefers-reduced-motion: reduce`, so you rarely need to opt out by hand.

Open any component's **Canvas** tab to edit `variant`, `duration`, `easing` and
`open` live from the Controls panel, and use the toolbar's remount control to
replay an animation.
