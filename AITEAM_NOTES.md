# LoomShift

Stub implementation for: As a user, I can dismiss the dialog via backdrop click or Escape key

Drafted by the LoomShift Product Owner agent.

Acceptance Criteria
- Clicking outside the dialog closes it and fires onClose callback
- Pressing Escape closes the dialog and fires onClose callback
- Focus returns to the triggering element after close

Estimate: 2 story point(s)
